# YoriAI Android starter

A minimal Android WebView shell with a compact green sliding drawer UI.

## Build on GitHub (phone-friendly)
1. Create a new GitHub repository named `YoriAI`.
2. Upload the contents of this folder to the repository root (not the containing folder itself).
3. Open the **Actions** tab and allow GitHub Actions if prompted.
4. Open **Build YoriAI APK** and press **Run workflow** (or wait for the push build).
5. When the run finishes, open it and download the `YoriAI-debug-apk` artifact.
6. Extract the artifact ZIP and install `app-debug.apk` on your Android phone.

This is an early companion-app shell, not a game modification. It does not inject into or control Clash Royale. Screenshot analysis, full card artwork/catalogue, and cloud-shared configurations are not implemented yet.
